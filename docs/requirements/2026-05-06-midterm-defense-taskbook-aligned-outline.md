# 中期答辩 PPT 大纲（任务书对齐版）

## 课题名称

基于大语言模型的智能化毕业设计选题双向选择系统设计与实现

## 汇报定位

本版 PPT 以任务书为准，围绕“选题双向选择”主线展开，智能问答、文档辅助、任务看板和前端工作台都作为支撑模块展示。

## 第 1 页：封面

标题：基于大语言模型的智能化毕业设计选题双向选择系统设计与实现

副标题：中期答辩汇报

- 课题关键词：双向选择、智能推荐、文档辅助、过程管理
- 说明当前展示以中期成果和任务书对齐为主

## 第 2 页：课题背景与研究意义

核心内容：

- 传统毕设系统偏重流程记录，学生在选题理解和资料消化上支持不足
- 选题阶段存在信息不对称，学生与教师都难以快速完成精准匹配
- 引入大语言模型后，可为选题、问答、文档理解和过程跟踪提供辅助

## 第 3 页：研究内容与技术要求

核心内容：

- 智能选题推荐模块：课题画像、学生画像、Top-N 推荐
- 智能问答与 AI 文档辅助模块：毕设场景问答、PDF 摘要、要点提取
- 过程管理与进度看板模块：阶段任务、里程碑、进度可视化
- 技术要求：前后端分离、接口契约、异步任务、状态轮询、统一错误格式

## 第 4 页：总体方案与技术路线

核心内容：

- 前端：选题浏览、问答、文档、看板与首页概览
- 后端：Flask + RESTful API + 分层服务
- 异步任务：pending / running / done / failed
- AI 接入：大模型 API + 文档上下文 + 任务状态追踪

## 第 5 页：总体进度与阶段完成情况

核心内容：

- 已完成：任务书梳理、接口契约、后端核心分层、前端项目骨架
- 已完成：登录、Topics、Chat、Documents、Taskboard 页面联通
- 当前重点：补齐推荐闭环、志愿状态、真实看板数据与首页统计
