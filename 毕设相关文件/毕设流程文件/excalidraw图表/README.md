# Excalidraw 图表清单

本目录存放毕业设计论文正文中结构图、流程图和 E-R 图对应的 `.excalidraw` 源文件。当前图表采用毕业论文正文插图风格：黑白灰配色、低手绘感、正交或清晰关系线、用例/结构/E-R 关系线不带箭头，业务流程和状态流转使用方向箭头。

注意：本目录中的图表已经经过手工精修，后续不要直接运行 `scripts/generate-excalidraw-diagrams.js` 覆盖本目录，否则会丢失手工布局与论文风格调整。
