# Word 排版前检查清单

本文档基于 `毕业论文正式稿-Markdown整合版.md` 整理，用于在 Markdown 转 Word 前逐项核对。学校模板文件为：

`C:\Users\ChiChou\Desktop\10 本科生毕业设计（论文）论文模板（2019年1.3版）.doc`

## 一、正式论文顺序检查

- [ ] 封面：使用学校模板封面，不从 Markdown 直接生成。
- [ ] 诚信声明：使用模板原文，检查签名、日期位置。
- [ ] 授权声明：使用模板原文，检查签名、日期位置。
- [ ] 中文摘要：放在目录前，保留“摘要”和“关键词”。
- [ ] Abstract：紧接中文摘要后，保留“Abstract”和“Keywords”。
- [ ] 目录：由 Word 自动生成，不手工复制 Markdown 标题。
- [ ] 正文：第1章至第5章，章节编号连续。
- [ ] 参考文献：置于正文之后，致谢之前。
- [ ] 致谢：置于参考文献之后。
- [ ] 附录：置于致谢之后，当前包括附录A至附录D。

## 二、Markdown 标题到 Word 样式映射

- [ ] `# 第1章 引言` 至 `# 第5章 结论与展望`：映射为 Word“标题 1”。
- [ ] `## 1.1 研究背景` 等二级标题：映射为 Word“标题 2”。
- [ ] `### 1.3.1 ...` 等三级标题：映射为 Word“标题 3”。
- [ ] `# 摘要与关键词` 不建议作为正式标题进入 Word，应拆为“摘要”和“Abstract”两个模板规定标题。
- [ ] `# 参考文献`、`# 致谢`、`# 附录`：按学校模板设置为一级标题样式。
- [ ] `## 附录A 核心接口说明` 等附录标题：建议使用附录标题样式或“标题 2”，目录层级按模板要求确认。

## 三、目录收录范围检查

- [ ] 应进入目录：摘要、Abstract、正文第1章至第5章、参考文献、致谢、附录。
- [ ] 应进入目录：正文一级标题、二级标题；三级标题是否进入目录按学校模板要求确认。
- [ ] 不应进入目录：图题、表题、公式编号、正文中的“关键词/Keywords”行。
- [ ] 不应进入目录：Markdown 文件名、图片文件路径、附录表格内部字段。
- [ ] 目录生成后检查页码是否自动更新。
- [ ] 转 Word 后执行一次“更新整个目录”。

## 四、图题、表题、公式编号检查

- [ ] 图编号按章节连续：第3章图3-1至图3-10，第4章图4-1至图4-3。
- [ ] 表编号按章节连续：表2-1、表3-1至表3-4、表4-1至表4-8；附录表使用表A-1、表B-1、表C-1、表D-1。
- [ ] 公式编号保留为公式2-1、公式2-2。
- [ ] 正文中图表公式应先引出，再插入图、表或公式。
- [ ] 图题一般置于图片下方，居中。
- [ ] 表题一般置于表格上方，居中。
- [ ] 公式居中，编号右对齐；编号格式统一为“（2-1）”或学校模板规定格式。
- [ ] Word 中不要把 Markdown 图片语法 `![图...](...)` 原样保留，应替换为真实图片。

## 五、图片插入检查

- [ ] 插图以 `论文图片/exported/` 中的 PNG/SVG 为主。
- [ ] 系统页面截图以 `论文图片/captures/` 为补充，不使用 excalidraw。
- [ ] 插图时使用“正文图号与原图片文件名映射表”核对，不按旧文件名编号直接排版。
- [ ] 正文图号与文件名不一致时，以正文图号为准。
- [ ] 图片插入后检查清晰度，避免被 Word 自动压缩过度。
- [ ] 宽图建议设置为页面正文宽度以内，保持等比例缩放。
- [ ] 流程图、架构图、ER图优先使用清晰导出图。
- [ ] 截图类图片检查是否包含敏感信息、调试信息或无关浏览器界面。

## 六、表格排版检查

- [ ] 表格统一使用三线表或学校模板规定表格样式。
- [ ] 表题置于表格上方。
- [ ] 表格字号应小于或等于正文，通常用小五或五号，按模板确认。
- [ ] 表格跨页时启用“重复标题行”。
- [ ] 跨页表格不要出现单独一行标题或孤立表尾。
- [ ] 检查列宽，避免文字挤压、强制换行过多。
- [ ] 技术名词如 Flask、Redis、PostgreSQL、Worker 不要被错误断行。
- [ ] 附录表格编号与正文表格编号区分，使用表A-1、表B-1等。

## 七、参考文献检查

- [ ] 参考文献编号保持 `[1]` 至 `[60]`。
- [ ] 正文引用编号不改动，Word 阶段只排版不重排。
- [ ] 检查编号是否使用半角方括号。
- [ ] 参考文献段落设置悬挂缩进。
- [ ] 检查中文标点、英文标点是否符合 GB/T 7714。
- [ ] 检查 `[J]`、`[C]`、`[M]`、`[D]`、`[R]` 类型是否准确。
- [ ] arXiv 技术报告类条目重点复核是否应由 `[J]` 改为 `[R]`。
- [ ] 会议论文检查是否使用 `[C]`。
- [ ] 学位论文检查是否使用 `[D]`。
- [ ] 参考文献英文题名大小写按 GB/T 7714 和学校要求统一。

## 八、附录处理检查

- [ ] 附录标题使用“附录A 核心接口说明”等格式。
- [ ] 附录表格使用表A-1、表B-1、表C-1、表D-1，不与正文表编号混用。
- [ ] 附录是否插入实际截图需按学校要求决定。
- [ ] 如果正文已有截图，附录可只保留截图说明表，避免重复堆图。
- [ ] 若附录插入实际截图，应使用 `captures/` 或 `exported/` 中正式图片。
- [ ] 附录不放大量源码、完整日志或 README 式启动命令。
- [ ] 附录D保留运行环境与验证说明，不扩展成部署手册。

## 九、转 Word 前最后核对

- [ ] 删除 Markdown 专用符号：图片路径语法、反引号代码标记按模板处理。
- [ ] 检查中文与英文、数字之间空格是否统一。
- [ ] 检查章节标题是否没有多余空行。
- [ ] 检查“Web系统开发技术基础”是否按需要改为“Web 系统开发技术基础”。
- [ ] 检查所有图、表、公式在 Word 中可被交叉引用或手工编号一致。
- [ ] 检查“摘要与关键词”是否拆成模板要求的正式摘要页。
- [ ] 检查正文未混入规划表、核验说明、引用分配表等过程文件内容。
- [ ] 保存 Word 初稿后，先更新目录，再检查页码、图表位置和参考文献分页。
