## 附录目录建议

### 附录A 核心接口说明

本附录建议选取系统中具有代表性的接口进行说明，不需要完整粘贴 `spec/contract.yaml`。可按业务域整理为表格，说明接口名称、请求方法、接口路径、主要参数和功能说明。

建议包含以下接口类别：

| 接口类别 | 建议说明内容 | 对应材料 |
| --- | --- | --- |
| 用户与身份认证接口 | 登录、刷新访问令牌、登出、当前用户资料查询与更新 | `spec/contract.yaml` 中 `identity` 相关接口 |
| 学期与配置接口 | 学期列表、学期详情、学期配置维护、学期级 LLM 配置 | `spec/contract.yaml` 中 `terms` 相关接口 |
| 课题管理接口 | 课题列表、课题创建、课题更新、课题审核与发布 | `spec/contract.yaml` 中 `topic` 相关接口 |
| 志愿与指导关系接口 | 志愿提交、撤销、教师决策、指导关系查询 | `spec/contract.yaml` 中 `selection` 相关接口 |
| 推荐接口 | 学生 Top-N 推荐、推荐解释字段 | `spec/contract.yaml` 中 `recommendations` 相关接口 |
| 文档与对话接口 | 文档上传、文档任务查询、会话消息发送、异步任务查询 | `spec/contract.yaml` 中 `document`、`chat` 相关接口 |

建议附录中只保留核心接口表，不粘贴完整 OpenAPI 文件。对于异步接口，可补充说明其返回 `202` 受理结果，并通过任务状态查询后续执行情况。

### 附录D 部分核心配置与运行说明

本附录建议给出系统运行所需的关键配置和启动说明，帮助读者理解系统如何在本地或容器环境中运行。该部分不宜展开大量源码，只需说明核心环境、服务组成和运行步骤。

建议包含以下内容：

| 内容类别 | 建议说明 |
| --- | --- |
| 运行环境 | Python、Node.js、PostgreSQL、Redis、Docker Compose 等基础环境 |
| 服务组成 | 前端服务、Flask Web 服务、PostgreSQL、Redis、Worker 进程 |
| 关键地址 | 前端访问地址、后端 API 基础地址、健康检查接口 |
| 异步队列 | `chat_jobs`、`pdf_parse`、`document_jobs`、`keyword_jobs`、`reconcile_jobs` 的用途 |
| 任务状态 | `pending`、`running`、`done`、`failed` 的含义 |
| 基本运行步骤 | 启动基础服务、运行后端、运行前端、执行测试、查看健康检查结果 |

该附录可引用 README 和系统架构文档中的运行说明进行整理，但不建议粘贴完整配置文件。若需要展示配置，可选择少量关键环境变量或服务名称，并用文字解释其作用。

## 附录排版建议

建议附录按“接口说明—测试结果—页面截图—运行说明”的顺序排列。接口说明服务于系统实现核查，测试结果服务于第4章验证，页面截图服务于系统效果展示，运行说明服务于复现实验环境。附录内容应以表格、截图和简要说明为主，避免大段代码和完整日志堆叠。
